# Image Grid Layout
This is a one page image layout, that demonstrates images of different sizes laid out in a grid format. 

## Technologies Used
1. **HTML** used to create the main headings and the different sections.
2. **CSS** controls all the layout, spacing properties and responsive behaviour.

## Development Tools
1. **Visual Studio** to write the code.
2. **GitHub** to make an online copy of my code, accessible through a link.

## Responsive Design
1. When the screen is  below 600px the Grid Layout changes to a vertical layout so that the image is not croped and clear on smaller screens.
2. When the screen is bigger than 600px the Grid Layout goes back to horizontal, shows the display in a grid shape.
3. This change so the user can have a clear view of the images on different ypes of devices. 

## How To Run The Project
To run the project clone it on vidula studio, download the **Live Server extension** then press the "Go Live" button on the bottom right of your screen.
The website will open on your default browser.
